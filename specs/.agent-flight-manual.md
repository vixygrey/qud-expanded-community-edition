# Agent Flight Manual

This directory stores the project records for a Qud mod with Python tooling and C# game scripts.

## Operational Rules

1. Read `specs/development-workflow.md` before you start a feature.
2. Read the architecture and context map before you define a feature.
3. Read the relevant charter and style specifications before you change shipped content.
4. Define observable acceptance criteria before you write production code or mod content.
5. Design a test or manual check for every acceptance criterion.
6. Record a failing test before implementation when automated tests apply.
7. Run `specs/validate-context.sh` before you complete a feature.
8. Update `state.yaml` after every phase transition.
9. Run `specs/archive-feature.sh` before you start another feature.
10. Stop and request human review when a change breaks a compatibility or architecture assumption.
